# Changelog

## 0.9.1.4
- Початковий реліз Kavita Add-on для Home Assistant на базі офіційної версії Kavita v0.9.1.4
- Підтримка архітектур aarch64, amd64, armv7
- Автоматичне персистентне сховище для SQLite бази даних у `/data/config`
- Автоматичне монтування бібліотек `/books`, `/manga`, `/comics` з `/share/kavita`
- Веб-інтерфейс та OPDS-сервер на порті 5000
- Підтримка вбудовування в Home Assistant (`panel_iframe` та `AllowIFraming`)
- Автоматична перевірка та оновлення релізів через GitHub Actions
